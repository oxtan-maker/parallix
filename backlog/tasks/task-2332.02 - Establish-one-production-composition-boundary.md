## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove competing composition roots and service-location cycles. Today, concrete adapter construction is scattered: the board projection factory lives in `application/`, TUI production construction lives in `interfaces/tui`, and `LegacyActiveAdapter` depends on `createMissionApplicationServices()` creating a cycle.

**Scope:**
- Move the board projection concrete factory out of `application/`.
- Move TUI production construction out of `interfaces/tui`.
- Break `LegacyActiveAdapter` → `createMissionApplicationServices()` dependency.
- Define explicit lifetime and ownership for the operator database.
- Ensure CLI and TUI use the same constructed application capabilities.

**Target:** Only `composition/**` constructs concrete adapters. No adapter imports `composition/**`. No application module imports concrete adapters.
<!-- SECTION:DESCRIPTION:END -->
