## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Migrate the remaining review-loop bounce paths onto the rebound kernel (TASK-2377.03) and remove the now-obsolete persisted retry state, since the per-local-failure budget keeps nothing across occurrences.

**Migrate to the kernel:**

- **Artifact recovery relaunches** (the review-loop's reviewer/implementer artifact-failure path and the artifact dispatcher's retry loop): each incomplete-artifact occurrence becomes a `rebound` call with a verify callback that re-consumes the artifacts. Today these paths relaunch and re-poll artifacts but never re-run a gate; the kernel makes the re-consume check explicit.
- **Poll-timeout recovery relaunches** (reviewer/implementer disposition timeouts): one `agent-timeout` reason; verify = re-poll with the recovery prompt's expectations.
- **Round-level cap**: a per-round bound on total agent relaunches (reviewer retries + implementer retries + artifact/timeout bounces + gate/hook bounces). Rounds themselves are still capped by the existing max-attempts; this caps the within-round relaunch fan-out that the per-occurrence budgets alone allow.

**Delete the persisted retry state** (per-local-failure budget = nothing to persist):

- review-state.json metadata retry counters (gate failure, hook failure, reviewer/implementer retry counts, artifact retry counts) and their metadata keys.
- The SQLite retry columns on `mission_reviews` (added for gate retries and hook retries) via a drop migration.
- The review-state mapping sync for those fields.
- The orphaned domain record methods (`recordGateFailureRetry`, `recordHookFailureRetry`) — never called, and no longer needed.
- Any remaining copied hook regex or override rule in the review-loop gate-handling module (the kernel's classifier replaces them).

**Preserved:** the review-round max-attempts cap; gatekeeper pushback (no agent involved); stale-blocked/parked recovery relaunch (disposition recovery, not failure bounce — stays as-is unless the checkpoint shows it shares a path with the kernel).

Out of scope: CLI and handoff bounce paths (TASK-2377.05).
