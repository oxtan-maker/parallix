## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Turn ADR 0051's intended architecture into executable dependency rules before moving more code. Currently the repository has import-boundary tests, but they use infrastructure-name blacklists rather than graph-based layer rules. This mission installs the intended dependency graph as an enforceable constraint.

**Intended dependency graph:**

```
domain      → domain
application → domain, application
adapters    → domain, application, adapters (local)
interfaces  → domain, application, interfaces (local)
composition → all implementation layers
entry       → composition and interface entrypoints
```

The validation is graph-based: each layer declares its allowed imports, and violations are caught at test time rather than relying on naming conventions. Existing violations are collected into a temporary, explicit allowlist so the guard can be installed without blocking on legacy cleanup.
<!-- SECTION:DESCRIPTION:END -->
