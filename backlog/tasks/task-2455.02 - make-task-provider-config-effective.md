## Description

`config/workflow.config.schema.json` declares `adapters.tasks.provider` and
setup writes it, but task behavior remains backlog-md-specific. Reproduce with
this override:

```json
{ "adapters": { "tasks": { "provider": "other" } } }
```

`px config` exits zero and prints `other`, while task storage and lifecycle
operations do not select a provider implementation from the value. Define
provider selection and its supported values, or remove this field from the
public schema and setup output. Update the configuration reference after the
contract is implemented.

## Acceptance Criteria

- [ ] A regression test proves the configured provider selects a supported task
      adapter, or unsupported values are rejected and the field is removed from
      the public schema.
- [ ] `px config` and the configuration reference describe only supported
      provider behavior.
