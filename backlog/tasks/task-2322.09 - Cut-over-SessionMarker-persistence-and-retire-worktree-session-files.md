## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make the checked SessionMarker repository the sole live authority for resumable agent sessions. Move all create, lookup, resume, replace, and clear behavior behind application ports, import any needed worktree markers explicitly, then remove routine reads and writes under .workflow/sessions. Session identity must survive worktree cleanup and must not be confused with an inferred Attempt aggregate.
<!-- SECTION:DESCRIPTION:END -->

<!-- AC:BEGIN -->
