## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of wave TASK-2521 (read its architectural constraints and mandatory agent-slop checks; they apply here).

Depends on: Mission 5 (TASK-2521.05).

Purpose: establish a deterministic GO/NO-GO decision for cleanup.

### Work

Create/run an explicit migration command/process covering the current Parallix repository.

It must discover all files under the retired workflow areas rather than relying only on a hard-coded list of expected filenames.

For every discovered file, classify it as:

* imported into authoritative Mission state;
* imported into the local task provider;
* already represented identically in authoritative state;
* product/configuration content that must remain;
* explicit large/external artifact retained by reference;
* intentionally obsolete with no unique retained information; or
* **UNRESOLVED**.

For data-bearing legacy files, compare imported/current state strongly enough to catch silent loss. Use IDs, parsed values, counts and digests where meaningful; do not compare only file counts.

Migration must be repeatable/idempotent.

Before cleanup, take/test the supported database backup path appropriate to ADR 0053.

### HARD GO/NO-GO gate

Cleanup is authorized ONLY when all of the following are true:

```text
unresolved legacy files                 = 0
unparsed data-bearing files             = 0
conflicting duplicate records           = 0
normal-runtime readers of retired paths = 0
normal-runtime writers of retired paths = 0
required Mission context missing        = 0
required task records missing           = 0
migration verification failures         = 0
```

Any non-zero value STOPS the wave before Mission 7 (TASK-2521.07).

Do not "fix" the count by adding ignore rules unless the ignored class is proven non-authoritative/non-required under the landed ADRs.
