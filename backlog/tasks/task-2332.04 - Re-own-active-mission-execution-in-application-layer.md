## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Replace `ActivePort` / `LegacyActiveAdapter` as a disguised legacy workflow with a real application use case. Currently the active mission workflow is almost entirely inside the adapter:

```
ActiveService → LegacyActiveAdapter → almost the entire workflow
```

The target is a proper use case that owns sequencing and partial-failure policy:

```
ExecuteMission
  → workspace port
  → agent execution port
  → lifecycle/store port
  → telemetry port
  → handoff/review port
```

This is the largest behavioral mission in the sequence and depends on stable composition and contract ownership from prior missions.
<!-- SECTION:DESCRIPTION:END -->
