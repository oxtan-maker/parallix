- [ ] #4 Cold install, upgrade from the supported prior schema, full legacy import, restart, concurrent stale mutation, interrupted migration, backup and restore, corrupt database, and unavailable database behavior pass end-to-end without file fallback.

- [ ] #6 The verification suite proves direct edits to every retired legacy file cannot affect runtime state and database mutation failures cannot partially update external effects.
- [ ] #7 Current architecture and user documentation names the operator database authority and remaining external boundaries without restating or competing with ADR decisions.
- [ ] #8 No deferred migration TODO, undeclared domain record, shadow write, bidirectional synchronization, or UI-only persistence remains when the task is completed.
