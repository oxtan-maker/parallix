## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of wave TASK-2521 (read its architectural constraints and mandatory agent-slop checks; they apply here).

Depends on: Missions 2, 3 and 4 (TASK-2521.02, .03, .04).

Purpose: complete the behavioral cutover BEFORE deleting historical files.

### Work

Remove normal-runtime reads/writes whose concepts now have supported authorities.

At minimum inspect and address:

* Mission-directory discovery used as evidence of Mission existence;
* `MISSION.md` existence/dirty/committed checks;
* `MISSION.md` parsing of gates/refinement/context;
* CP-file discovery/parsing/commit checks;
* auto-generation of `CP-1.md`;
* review-event Markdown auto-export;
* review-state/NEL compatibility files;
* task-file fallback summary writes;
* board/read adapters that scan repository task/mission directories;
* closeout/integration behavior that writes task files merely to mirror DB state;
* tests whose assertions accidentally make these files part of the product contract.

Replace trust checks with equivalent or stronger semantic checks:

* required Mission state exists;
* required checkpoint evidence exists and validates;
* required Goal Check references validate;
* verification/gates execute against the correct tree;
* review state is tied to the correct revision;
* Git facts come from Git;
* external-provider facts come from the provider.

Delete the synthetic checkpoint remediation path. Missing semantic evidence is sent back to its producer or fails closed according to ADR 0048.

Explicit legacy import and explicit caller-requested export remain allowed. They must not be called by normal lifecycle execution.
<!-- SECTION:DESCRIPTION:END -->
