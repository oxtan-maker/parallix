## Description

`px config` calls `validateWorkflowConfig`, but that validator only rejects an
invalid top-level object, invalid adapter containers, and an invalid positive
integer for `adapters.agents.maxConcurrentCustom`. It does not enforce the
field-level types and enums declared by `config/workflow.config.schema.json`.

Reproduce in a temporary repository with:

```json
{ "adapters": { "review": { "provider": "unsupported" } } }
```

The command currently exits zero and prints an effective configuration, despite
the schema enum allowing only `forgejo`, `none`, or `null`. Make `px config`
exit non-zero with a structural-validation diagnostic for this and comparable
schema violations, while retaining the fallback-default output for invalid
files.

## Acceptance Criteria

- [ ] A regression test named for an enum or type violation proves `px config`
      exits non-zero and reports a structural-validation diagnostic.
- [ ] Validation covers every documented schema field or the schema explicitly
      narrows to the validation that the runtime enforces.
