## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Complete the command-layer ownership work deferred from TASK-2332.06. This is a responsibility split, not a directory rename: inbound parsing and rendering belong in interfaces, workflow policy and sequencing belong in application use cases over application-owned ports, concrete Git/Backlog/Forgejo/filesystem/process mechanisms remain adapters, and composition only wires them. Preserve the public CLI contract while removing direct multi-integration orchestration from adapter command modules.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Every production CLI command is inventoried with its inbound interface, application use case, ports, concrete adapters, and composition wiring; the inventory covers all current modules under src/adapters/cli/commands/.
- [ ] #2 integrate, stats, handoff, draft, and the remaining command modules no longer sequence Git, Backlog, Forgejo, verification, filesystem, process, or agent-provider operations from src/adapters/cli/commands/.
- [ ] #3 Argument parsing, request translation, exit-code mapping, text/JSON rendering, and CLI-specific help live under src/interfaces/cli/.
