## Description

The command-level tests observe an `exitFn(1)` for malformed and structurally
invalid configuration, but the real process exits zero. Reproduce from a
temporary directory containing malformed `workflow.config.json`:

```sh
px config
echo $?
```

The command prints `invalid JSON` and fallback defaults, then reports `0`.
`src/entry/px.ts` assigns the resolved return from `run()` to
`process.exitCode`, overwriting the exit status set by the config command.
Preserve a non-zero process status for failed config validation without changing
the fallback-output behavior.

## Acceptance Criteria

- [ ] An integration or process-boundary test proves `px config` exits non-zero
      for malformed JSON and structural violations.
- [ ] The existing command tests and the real CLI process agree on the exit
      status for each configuration failure.
