## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Produce one understandable inbound architecture for CLI and TUI. Today, command dispatch is split across multiple modules with transitional re-exports and platform/runtime dependencies into interfaces.

**Scope:**
- One command parser/registry/dispatcher.
- Minimal `entry/px.ts`.
- CLI and TUI invoke application capabilities rather than platform commands.
- Remove transitional `interfaces/cli` re-exports.
- Make stale-command protection part of the normal command contract rather than an optional alternate API.
- Decide whether `platform/runtime` remains a meaningful package or is only migration residue.

**Target:** Exactly one canonical command-dispatch path. TUI does not depend on command implementation modules. No `platform` → `interfaces` dependency.
<!-- SECTION:DESCRIPTION:END -->
