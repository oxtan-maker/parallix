## Description

`config/workflow.config.schema.json` declares `product.targetUser` as a string
and `workflow.config.json` accepts it, but no runtime consumer reads it. Create
a temporary repository containing:

```json
{ "product": { "targetUser": "release engineers" } }
```

Then run `px config`: the value is printed, but no user-facing runtime behavior
uses it. Either connect this setting to a defined user-facing behavior or remove
it from the supported schema and setup-generated config. Update the config
reference when the contract is settled.

## Acceptance Criteria

- [ ] A regression test proves the configured value changes its declared
      user-facing behavior, or the field is absent from both generated config
      and the public schema.
- [ ] `px config` and the configuration reference agree with that behavior.
