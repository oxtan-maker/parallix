## Description

TASK-2322.12 cannot complete its ADR 0053 cutover because the existing `Review`
aggregate has no representation for the review-loop phase, reviewer and implementer
retry counters, stage-launch de-duplication metadata, or event history. These are
live values currently read from `review-state.json` and review-event Markdown files.

Define and implement the approved domain/schema/application-contract capability for
that workflow state. Use a single SQLite authority with CAS-safe mutation. Migrate
the review loop, commands, and statistics projection to it; add positive persistence
and recovery coverage; then remove the declared compatibility paths in TASK-2322.12.

## Acceptance Criteria

- [ ] The Review model and approved application contract represent all live
  review-loop state without lossy inference.
- [ ] Review state, event history, statistics, and identity resolution use SQLite
  as their only routine authority.
- [ ] Concurrent stale mutation fails safely and restart retains phase, retries,
  stage-launch metadata, and event history.
- [ ] The review-event tests contain positive SQLite-path coverage and no obsolete
  legacy-import skips.
- [ ] Connection ownership is coordinated with the production composition root;
  no unclosed secondary resolver connection remains.
