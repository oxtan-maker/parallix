## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Base: TASK-2500. Mission 3 of 6. Implement `github-pr`, where Parallix owns mission execution/review but GitHub owns final integration into the repository primary branch.

WORKFLOWS:
```text
main
  -> developer/feature branch
      -> Parallix mission branch
      -> implement -> review -> integrate mission into developer branch
      -> push/update GitHub PR -> GitHub checks/review/policy -> GitHub merges to main
```
and simpler:
```text
main
  -> Parallix mission branch
  -> GitHub PR -> GitHub merge
```

LIFECYCLE stages (Parallix owns first part, GitHub owns final merge):
```text
Parallix mission work complete -> review approved -> local gates passed
-> PR submitted/updated -> GitHub checks pending -> GitHub integration observed -> mission complete
```
`px integrate` must NOT treat a local update of repository `main` as mission completion in this mode.

SUPPORT a configured integration target/base branch, e.g.:
```text
main
  \
   feature/payment-rewrite
       \
        mission/task-1234
```
Completing the mission may mean integrating `mission/task-1234` into `feature/payment-rewrite`; the feature branch itself later goes through GitHub PR into `main`.

DEPENDENCY ORDER: base TASK-2500. Depends on Mission 1 (TASK-2500.01). Can run largely in parallel with Mission 2 (TASK-2500.02).
<!-- SECTION:DESCRIPTION:END -->

## Mission Requirements

- In `github-pr` mode, `px integrate` must NOT treat a local update of repository `main` as mission completion.
- GitHub merge state must be OBSERVED, not inferred from local branch state. Closing a mission that requires GitHub integration requires fresh external evidence the expected PR/commit merged.
- Support a configured integration target/base branch rather than assuming `main`.
- Do NOT assume the resulting GitHub merge commit has the same SHA as the Parallix mission head; this mode explicitly permits GitHub-owned integration strategies. Verify the appropriate relationship/tree/integration evidence instead.

Recovery for: PR closed without merge; branch updated after Parallix review; PR merged with an unexpected resulting tree; PR rebased/squashed by repository policy; GitHub unavailable; target/base branch changed.
