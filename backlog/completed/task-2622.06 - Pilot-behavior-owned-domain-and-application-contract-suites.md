3. Replace the legacy entries in `test/lib/shared-unit-files.json` with the new suite names (unit suites without shared-state markers stay shareable; suites using `mock.*` stay isolated automatically).
4. Compare per-file LCOV identities with `tools/coverage-comparison/compare-slice-coverage.ts` and measure CPU per file before and after.
