## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Separate checked AgentBlock state from agent definitions and configuration. Import the existing local block overlay once, route every block decision and mutation through the database-backed application boundary, and remove block-state lookup and writes from agents.local.json. Static agent configuration and launcher discovery remain external configuration inputs, not competing block authorities.
