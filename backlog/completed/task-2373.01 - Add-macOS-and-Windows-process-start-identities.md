## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-2373 uses Linux /proc/<pid>/stat field 22 to distinguish PID reuse. On macOS and native Windows, the current liveness probe remains safe through Node's cross-platform process existence check, but it cannot distinguish a recycled PID and therefore relies on expiry. Add the smallest native per-PID start-identity lookup for those platforms without broad process-table scans; retain conservative fallback when the identity cannot be read.
<!-- SECTION:DESCRIPTION:END -->
