## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Several CLI command modules were carried over from JavaScript and never fully converted. They still use JSDoc type annotations, `// @ts-nocheck`, `// @ts-ignore -- retained ... dynamically typed`, and `/** @type{any} */`. Affected files at review time: `src/adapters/cli/commands/` `draft-stats.ts`, `stats-report-rendering.ts` (which has a `// @ts-nocheck` mid-file at line 22, where the directive has no effect, plus about 50 `@ts-ignore` lines), `active.ts`, `draft-setup.ts`, `stats-report.ts`, `handoff.ts`, `draft-conflicts.ts`, `draft-prompts.ts`, `draft.ts`, and `stats.ts`.

The outcome is idiomatic TypeScript in these modules: real types, not JSDoc, and no suppression directives. Mixed JS/TS idioms make the codebase look unfinished to reviewers and hide real type errors. Stats rendering and normalization should operate on a typed row model rather than `any`.

Independent of the handoff use case subtask; `handoff.ts` here is the thin CLI adapter, not the application use case.
<!-- SECTION:DESCRIPTION:END -->
