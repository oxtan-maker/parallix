## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ambient `process.env` reads are spread across about 50 production files, so the supported environment is hard to discover and tests must mutate global state. AGENTS.md names the composition root as the configuration authority, but nothing enforces it.

This mission builds the mechanism and proves it end to end on a first vertical slice; TASK-2668.08 migrates the remaining files.

- A typed `ParallixConfiguration` port in `src/application/ports/configuration.ts`, resolved once from the host environment in `src/composition/config.ts` (the only module that may interpret variables), frozen and passed inward as narrow slices. Child-process seams may keep spreading the host environment.
- A guard test (`test/unit/repository/ambient-environment-guard.test.ts`) that fails on any interpreted read outside the config module, with a shrinking allowlist of files not yet migrated and a stale-entry check, like the 500-line cap.
- First slice migrated with explicit configuration and no `process.env` mutation in tests: decision provider and review classification (`config.decision`), and the default-UI launch decision (`config.runtime`). `run()` resolves configuration once and threads it through the command registry and production service graph.

The operator approved the composition-root ownership boundary at the first handoff bounce.
<!-- SECTION:DESCRIPTION:END -->
