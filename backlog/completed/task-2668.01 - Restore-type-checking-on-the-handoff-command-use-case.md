## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`src/application/handoff-command-use-case.ts` (~1,630 lines) is the central handoff workflow: final gate, rebase, PR create/update, gatekeeper pre-review, declared gates, checkpoint recording, and the review transition. Its header says it reaches the outside world only through typed `HandoffWorkflowPorts`, and AGENTS.md requires typed application ports, but the file starts with `// @ts-nocheck`, so none of those port contracts are checked by the compiler.

The outcome is a handoff use case the TypeScript compiler fully checks against its ports, so a port signature change breaks the build instead of failing at runtime. The README says mechanics "live in tested code rather than in prompts"; after this task that claim must also hold for type safety on the handoff path, or the README wording must be corrected to match reality.

The file is also on the 500-line cap exception list. Typing it may expose cohesive seams; take them where they fall out naturally, but restoring type checking is the goal here, not size reduction (see the god-file subtask).
