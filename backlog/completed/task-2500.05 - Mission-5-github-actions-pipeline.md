## Mission Requirements

- Use a supported Node version satisfying Parallix's declared engine requirement.
- Clean checkout and deterministic dependency installation.
- Run the GitHub-safe verification command established in Mission 4.
- Use dependency caching only where it does not weaken reproducibility.
- Name the required status check deliberately and stably, e.g. `ci-required`. Do NOT dynamically change the check name because branch protection depends on it.
- Set sensible permissions rather than broad default write access.
- Use concurrency cancellation where appropriate for superseded PR commits, but do NOT cancel verification for immutable publication candidates still needed by `github-publish`.
