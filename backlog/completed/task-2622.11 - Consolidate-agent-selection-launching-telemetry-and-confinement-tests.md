### Method and comparison procedure

1. Merge is mechanical: each legacy body is wrapped unchanged in a `describe` named for its behavior and task IDs; imports are unioned; `mockModule` facades for one URL are collapsed to one shared handle, with a single `installModuleMocks()`.
2. Coverage baseline: pre-migration revision `43732c443` (production source identical to the migrated tree), each legacy file run alone with `tools/coverage-comparison/compare-slice-coverage.ts --checkout <baseline checkout> --files <legacy files> --out baseline.info`; the candidate is the same command on the migrated files; compare with `--compare baseline.info candidate.info`. The comparison fails on any lost covered line or changed executable denominator.
3. Replace the legacy entries in `test/lib/shared-unit-files.json` with the new suite names (shared-state markers keep a suite isolated automatically).
