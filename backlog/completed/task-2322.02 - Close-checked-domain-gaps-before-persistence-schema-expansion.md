## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Prove that the checked domain can express each behavior the migration and UI require before adding tables or adapter records. Map requirements to the current names Mission, CheckpointData, Review, MissionOutcome, AgentRunMeasurement, KnownRepository, SessionMarker, LaneTransitionEvent, and AgentBlock. Add a domain concept only when a current consumer needs identity, lifecycle, or invariants that these concepts cannot represent. In particular, do not infer an Attempt entity from legacy files or a convenient schema shape.
<!-- SECTION:DESCRIPTION:END -->
