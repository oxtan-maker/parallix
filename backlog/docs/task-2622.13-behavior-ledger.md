## Routing rules

1. Mixed / task-named suites route to the owning application contract, not to a
   filename guess. See ledger schema below.
2. Distinct input / error / order / state variants are retained; only
   semantically equivalent setup is collapsed.
3. Task IDs stay in case names as regression provenance; stable suite names do
   not carry the wave task id (AC#7).
4. New integration tests are classified in `test/lib/test-categories.ts` with
   local-only GitHub-runner dependency reasons named.
5. No giant files: `src/`+`web/` <= 500, tests <= 1000 (debt in
   `test/file-size-cap.test.ts`).

## Consolidation of event-history fixtures (the stated why)

Cohort and lifecycle fixtures each build a fixed event history with explicit
clocks from hand-authored lane events and usage records. The merged suites share
one explicit-clock event-history fixture (`test/fixtures/cohort-events.ts`) that
produces the seeded completed-mission history pinned to a rolling seven-day
decision window, removing the per-file duplication.
