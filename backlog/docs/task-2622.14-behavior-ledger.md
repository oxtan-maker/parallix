## Routing rules

1. Merged suites wrap each legacy file in a `describe` named for the guarantee
   and the historical task ID; every case keeps its original name and body.
2. No scenario is deleted: case counts are equal before and after (92 → 92 for
   the 19 touched source files).
3. Tier is preserved. Sources with file-wide module mocks (`active`, `status`,
   `config-command`, `product-config*`, `external-target-resolution`,
   `task-metadata-pure`) were not merged with unmocked suites.
4. Duplicated setup collapsed only where equivalent: the three temp-dir helpers
   in the config suites became one `withTempDir`/`withConfig`.
