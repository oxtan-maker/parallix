The combined plain integration ceiling is 395 seconds, the sum of its tier
ceilings. Suite accounting includes the waited test process tree and its
reporters/transpilation; separately invoked canonical bundle construction and
the outer launcher are outside these suite limits. This is not whole-gate CPU
accounting or a matched 50% throughput claim.

Integration cases now enforce their worker CPU plus reaped children and their
waited descendants through a stable N-API `getrusage(RUSAGE_CHILDREN)` counter.
Per-owner plain/covered case limits use measured maxima, 50% margin, rounding
up to 50 ms and a 100 ms minimum. Newly added unprofiled cases have a finite
500 ms fallback. Missing modules/reports, invalid values, wrong nesting and
concurrent siblings fail closed. Limits include `afterEach` and test-owned
`t.after()` teardown; nested cases are charged exclusively.

Representative hook-case ceilings are now 400/450 ms for repository gates,
350/400 ms for the real gate-process contract, and 250/250 ms for integration
pipeline cases (plain/covered). Larger process-contract cases retain their own
measured limits. Focused integration invocation automatically retains its CPU
hook rather than receiving an in-process-only unit counter.

The unit per-case 1,000 ms and plain 500 ms headroom contracts remain. Finite
wall watchdogs and process-group cleanup remain independent hang protections.
Hosted timing suspension remains unchanged. Local integration accounting needs
a C compiler and Node N-API headers; the counter has source support for Linux
and macOS, but these measurements were made on Linux.

The initial profiles preceded the teardown-counter repair; an enforced plain
integration replay exposed one 164 ms case against a 150 ms ceiling. Its limit
was recalibrated from the new measurement with the same margin. A synthetic
checkout cleanup test also needed the new executable policy copied into its
fixture. Both focused repairs passed, followed by the complete covered CI and
local runs. The isolated covered calibration was not repeated after that
repair; corrected accounting was validated separately in plain headroom and
covered fast execution.
