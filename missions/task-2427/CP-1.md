# CP 1 — Typed draft boundary at the controller (application layer)

## Summary of work done

Moved `draft:create` from `UNAVAILABLE_CAPABILITIES` into `INTEGRATED_CAPABILITIES` in `src/application/controller/board-command.ts`; the other four kinds keep their reasons. The `BoardCommandPayload` union gained no member for `draft:create` — the envelope `missionId` is the entire request (no argv, options bag, path, env, or agent-launch field), documented at the type definition.

`src/application/draft-command-use-case.ts` gained the narrow typed entry `executeForSlug(slug)`. It delegates to a new private `run(args, options, abortOnExit)` that owns the exact same 9-step sequence (`preflight → setup → scaffold → intake → transition → launchAgent → postProcess → commitSafety → finalTransition`) — no second path, no reimplementation. `execute(args, options)` (CLI) calls `run` with `abortOnExit=false` and is behavior-identical; `executeForSlug` calls it with `abortOnExit=true`, where any exited context becomes a thrown `DraftWorkflowAbortedError` (new exported class) instead of a silent return. Post-preflight aborts route through the existing catch path, so current-work `blocked` publication is unchanged.

`src/application/controller/board-controller.ts`: `BoardMissionServices` gained the `draft` slot (the application-owned `DraftCommandUseCase`); `canExecute('draft:create')` reports the wiring; `dispatch` returns the typed `unavailableCapability` result for an unwired draft service *before* mission authority is touched (read-only graph stays read-only, zero store access); new `dispatchDraft` enforces the dispatch backstop — the mission is loaded from the store and must be in `backlog` (pre-draft state) or the request is `rejected('validation')` with zero workflow calls — then invokes `executeForSlug(request.missionId)` once and maps any thrown abort to `failure('execution', …)` (never `completed`). The existing stale-command guard applies to `draft:create` as to every non-intake kind.

No composition or TUI changes in this checkpoint.
