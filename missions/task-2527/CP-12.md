# CP-12: Authenticated loopback submission

## Summary

Added a writable-home preflight before requesting a SonarQube token, preventing
an API token from being minted when `tokens/sonarqube` cannot be stored. The
live local service accepted the supported administrator-token API flow.

With `FORGEJO_HOME` set to a writable shared local home, `npm run sonar:setup`
created `tokens/sonarqube` at mode `0600`. A clean shell with `SONAR_TOKEN`,
`SONAR_LOGIN`, `SONAR_PASSWORD`, and `SONAR_SCANNER_OPTS` unset then ran `npm
run sonar`. SonarQube recorded CE task
`23315ebd-5b04-41ad-aef9-1b459667a718` for project `parallix` with status
`SUCCESS`.
