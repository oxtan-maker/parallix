# CP-11: Shared local scanner-token bootstrap

## Summary

Replaced the obsolete anonymous-scan contract with the authenticated local
workflow required by this mission. `npm run sonar:setup` now creates or reuses
one SonarQube token through the local token API and writes it only to
`tokens/sonarqube` under `resolveForgejoHome()`, with mode `0600`. `npm run
sonar` loads that local token and supplies it to `sonar-scanner-npm`.

The focused test covers token creation, reuse, permissions, scanner injection,
and sibling-worktree discovery without Docker or a network service.
